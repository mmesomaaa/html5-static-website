HTML Navigation

HTML links allow users to move between webpages and different sections of the same webpage. Links are created using the <a> element, also called the anchor element.

The href attribute specifies the destination of a link. For example, <a href="semantic.html"> creates a link to the semantic HTML page.

What I Learned

I learned that navigation is an important part of organizing a website because it allows users to move between pages and find information. I also learned how relative paths work when files are stored in different folders.
