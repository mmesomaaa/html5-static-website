Figures and Images

The HTML img element embeds an image into a webpage. The src attribute identifies the image location and the alt attribute provides alternative text for the image [4].

Example

Important Image Attributes

  • src: identifies the location of the image.
  • alt: provides alternative text that describes the image.
  • width: specifies the image width.
  • height: specifies the image height.

What I Learned

Working with figures taught me that images need more than just a file path. Alternative text is important because it provides information about an image when the image cannot be viewed. I also learned that figure and figcaption can be used together to connect an image with its description.
